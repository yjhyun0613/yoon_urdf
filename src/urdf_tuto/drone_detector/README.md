# 🛸 드론 감지 모듈 (drone_detector)

이 폴더는 시뮬레이션 환경 내에서 공중에 떠 있는 드론(UAV) 객체를 카메라 영상을 통해 실시간으로 추적 및 감지하는 YOLO 기반 인지 모듈을 포함하고 있습니다.

## 📁 주요 구성 파일
* `drone_detector_01.py`: 실시간 카메라 프레임을 받아 드론 객체를 탐지하고 분류하여 바운딩 박스와 신뢰도를 시각화해 발행하는 ROS 2 노드입니다.
* `dron_detector.pt` / `drone_detector_01.pt`: 드론 감지를 위해 학습된 YOLOv8 모델 파일입니다.

## 🚀 실행 방법
아래 명령어를 사용하여 가제보 환경 및 드론 감지 인지 시스템을 작동시킵니다:
```bash
ros2 launch urdf_tuto drone_detect.launch.py
```

## 🛠️ 기능 특징
* **실시간 탐지 및 바운딩 박스**: 카메라 화면에서 드론의 위치를 특정하고 화면에 시각적으로 표시합니다.
* **ROS 2 토픽 발행**: 탐지 결과를 타겟 노드로 전송하여 이후 추적 및 제어 동작과 연동할 수 있습니다.
