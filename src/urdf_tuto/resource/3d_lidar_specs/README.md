# 실제 3D LiDAR 센서 스펙 정리

> 이 문서는 실제 상용 3D LiDAR 센서들의 사양을 정리한 참고 자료입니다.  
> Gazebo 시뮬레이션에서 라이다를 설정할 때 현실적인 파라미터를 적용하기 위한 기준으로 활용할 수 있습니다.

---

## 📌 현재 프로젝트 시뮬레이션 라이다 설정 (`robot_3d.xacro`)

| 항목 | 현재 설정값 |
| :--- | :--- |
| 채널 수 (Vertical Samples) | 16 |
| 수평 샘플 수 | 360 |
| 수평 FOV | 360° (-π ~ π) |
| 수직 FOV | 30° (-15° ~ +15°) |
| 최소 거리 | 0.3m |
| 최대 거리 | 12.0m |
| 업데이트 레이트 | 10Hz |
| 출력 형식 | `sensor_msgs/PointCloud2` |

> ⚠️ 현재 설정은 Velodyne VLP-16의 FOV와 채널 수를 모사하고 있지만, 최대 거리(12m)가 실제 VLP-16(100m)에 비해 매우 짧습니다. 시뮬레이션 성능을 위해 의도적으로 줄인 것으로 보입니다.

---

## 1. Velodyne (현재 Ouster에 합병)

> 2023년 2월 Ouster가 Velodyne을 인수합병. 현재 VLP-16, HDL-64E 등은 단종되었으나, 3D LiDAR의 기준이 된 제품군입니다.

### 제품별 스펙 비교

| 항목 | VLP-16 (Puck) | VLP-32C (Ultra Puck) | HDL-64E (S3) |
| :--- | :--- | :--- | :--- |
| **채널 수** | 16 | 32 | 64 |
| **최대 거리** | 100m | 200m | 120m |
| **거리 정확도** | ±3cm | ±3cm | ±2cm |
| **수평 FOV** | 360° | 360° | 360° |
| **수직 FOV** | 30° (+15° ~ -15°) | 40° (+15° ~ -25°) | 26.9° (+2° ~ -24.9°) |
| **포인트 레이트** | ~300,000 pts/s | ~600,000 pts/s | ~2,200,000 pts/s |
| **회전 속도** | 5~20Hz | 5~20Hz | 5~20Hz |
| **무게** | ~830g | ~925g | ~13.5kg |
| **가격 (참고)** | 단종 (이전 ~$4,000) | 단종 (이전 ~$8,000) | 단종 (이전 ~$75,000) |
| **주요 용도** | 로봇, 드론, 자율주행 | 자율주행, 매핑 | 자율주행 (Waymo 등) |

### Gazebo 시뮬레이션 파라미터 참고 (VLP-16 기준)
```xml
<horizontal>
    <samples>360</samples>         <!-- 또는 1800 (0.2° 해상도) -->
    <min_angle>-3.14159</min_angle>
    <max_angle>3.14159</max_angle>
</horizontal>
<vertical>
    <samples>16</samples>
    <min_angle>-0.261799</min_angle>  <!-- -15° -->
    <max_angle>0.261799</max_angle>   <!-- +15° -->
</vertical>
<range>
    <min>0.3</min>
    <max>100.0</max>
</range>
```

## 2. Ouster (REV7, L3 칩 기반)

> Velodyne 합병 후 Digital LiDAR (CMOS 기반) 기술로 통합. 산업용/자율주행 시장의 주요 제품군.

### 제품별 스펙 비교

| 항목 | OS0 (단거리) | OS1 (중거리) | OS2 (장거리) |
| :--- | :--- | :--- | :--- |
| **채널 수** | 32 / 64 / 128 | 32 / 64 / 128 | 32 / 64 / 128 |
| **최대 거리 (10% 반사율)** | 35m | 90m | 200m |
| **최대 거리 (절대)** | ~250m | 250m | 400m+ |
| **수평 FOV** | 360° | 360° | 360° |
| **수직 FOV** | 90° | 45° | 22.5° |
| **최대 포인트 레이트** | 10.4M pts/s | 10.4M pts/s | 5.2M pts/s |
| **방수/방진** | IP68/IP69K | IP68/IP69K | IP68/IP69K |
| **가격대** | $3,000 ~ $15,000+ | $3,000 ~ $15,000+ | $3,000 ~ $15,000+ |
| **주요 용도** | 실내 로봇, 물류 | 자율주행, 산업 | 고속도로, 장거리 감지 |

### 핵심 특징
- **L3 칩**: REV6 대비 감지 거리 2배, 정밀도 50% 향상
- **듀얼 리턴 모드**: 비/안개 환경에서 향상된 인지
- **동기화된 LiDAR/카메라 데이터** 출력 지원

## 3. Livox (DJI 자회사)

> 비반복 스캐닝(Non-repetitive scanning) 기술로 시간이 지날수록 FOV 내 포인트 밀도가 증가하는 특징.

### 제품별 스펙 비교

| 항목 | Mid-360 | HAP | Avia | Tele-15 |
| :--- | :--- | :--- | :--- | :--- |
| **최대 거리 (10% 반사율)** | 40m | 150m | 190m | 320m |
| **최대 거리 (절대)** | 70m | 150m | 450m | 500m |
| **FOV** | 360° × 59° | 120° × 25° | 70.4° × 77.2° | 14.5° × 16.2° |
| **거리 정밀도 (1σ)** | ≤2cm | <2cm | 2cm | 2cm |
| **각도 정밀도 (1σ)** | <0.15° | <0.1° | <0.05° | <0.03° |
| **포인트 레이트** | 200,000 pts/s | 452,000 pts/s | 240,000 pts/s | 240,000 pts/s |
| **스캐닝 방식** | 비반복 | 비반복 | 비반복/반복 | 비반복 |
| **가격대** | ~$700~$900 | ~$1,500+ | ~$1,500~$2,500 | ~$1,200+ |
| **주요 용도** | 로봇 내비게이션 | ADAS, 자율주행 | 드론 매핑 | 장거리 감지 |

### 핵심 특징
- **비반복 스캐닝**: 고정 시 시간 경과에 따라 포인트 밀도 자동 증가 → SLAM에 유리
- **가성비**: VLP-16 대비 1/5 가격으로 유사 성능
- **Mid-360**: 로봇용 가성비 최고 추천 센서

## 4. RoboSense (速腾聚创)

> 중국 기반의 LiDAR 전문 기업. 기계식/반고체 다양한 라인업 보유.

### 제품별 스펙 비교

| 항목 | RS-LiDAR-16 | RS-LiDAR-32 | Helios-16 | Helios-32 (F70) |
| :--- | :--- | :--- | :--- | :--- |
| **채널 수** | 16 | 32 | 16 | 32 |
| **최대 거리** | 150m | 200m | 150m | 150m |
| **수평 FOV** | 360° | 360° | 360° | 360° |
| **수직 FOV** | 30° (+15°~-15°) | 40° | 30° | 70° (-55°~+15°) |
| **수평 해상도** | 0.1° / 0.2° / 0.4° | 0.1°~0.4° | - | - |
| **수직 해상도** | 2° | 비균일 (중앙 0.33°) | 균일 분배 | 비균일 |
| **가격대** | ~$1,000~$2,000 | ~$2,000~$5,000 | ~$1,200+ | ~$1,500+ |
| **주요 용도** | 로봇 내비게이션 | 자율주행 | 로봇 범용 | 근거리 사각지대 제거 |

### 핵심 특징
- **Helios-32 F70**: 수직 70° FOV로 바로 아래 사각지대 최소화
- **고급 노이즈 제거**: 비/안개/눈 환경 필터링
- **-40°C 동작**: 극한 환경 대응

## 5. 제조사별 종합 비교

### 가격대별 추천

| 예산 | 추천 센서 | 가격 | 특징 |
| :--- | :--- | :--- | :--- |
| 💰 저예산 (~$1,000) | **Livox Mid-360** | ~$700~$900 | 360° FOV, 로봇 SLAM 최적 |
| 💰💰 중간 (~$2,000) | **RoboSense Helios-16** | ~$1,200+ | 16ch, 150m, 균일 빔 분배 |
| 💰💰💰 고급 (~$5,000+) | **Ouster OS1-64** | ~$5,000+ | 64ch, 90m, 10.4M pts/s |
| 💰💰💰💰 프리미엄 | **Ouster OS2-128** | ~$10,000+ | 128ch, 200m+, 장거리 |

### 스캐닝 방식 비교

| 방식 | 대표 제품 | 장점 | 단점 |
| :--- | :--- | :--- | :--- |
| **기계식 회전** | Velodyne VLP-16, Ouster OS1 | 균일한 360° 스캔, 검증된 기술 | 기계 부품 마모, 크기/무게 |
| **MEMS 기반** | Livox Mid-360, Avia | 소형, 저전력, 저가 | 제한된 FOV (일부 모델) |
| **Digital (CMOS)** | Ouster REV7 | 고해상도, 고신뢰성 | 높은 가격 |
| **Flash** | 일부 솔리드스테이트 | 움직이는 부품 없음 | 짧은 거리, 좁은 FOV |

## 6. Gazebo 시뮬레이션 설정 팁

### 현실적인 파라미터 vs 시뮬레이션 성능

시뮬레이션에서는 실제 스펙을 그대로 적용하면 성능이 크게 저하될 수 있습니다. 아래는 권장 타협안입니다.

| 항목 | 실제 (VLP-16) | 시뮬레이션 권장 | 현재 설정 |
| :--- | :--- | :--- | :--- |
| 수평 샘플 | 1800 (0.2°) | 360~720 | 360 ✅ |
| 수직 채널 | 16 | 16 | 16 ✅ |
| 수직 FOV | ±15° | ±15° | ±15° ✅ |
| 최대 거리 | 100m | 12~30m | 12m ✅ |
| 업데이트 레이트 | 10~20Hz | 10Hz | 10Hz ✅ |

> 💡 **최대 거리를 줄이는 것은 올바른 최적화 방법**입니다. 실내 환경(office_cpr)에서는 12m로 충분합니다.

### 32채널로 업그레이드 시 설정 예시 (VLP-32C 모사)
```xml
<vertical>
    <samples>32</samples>
    <min_angle>-0.436332</min_angle>  <!-- -25° -->
    <max_angle>0.261799</max_angle>   <!-- +15° -->
</vertical>
<range>
    <min>0.3</min>
    <max>30.0</max>  <!-- 실내에서는 30m 충분 -->
</range>
```
